# 커밋 제안

모든 변경이 완료되었으면 커밋하세요.

## Conventional Commits 형식
- feat: 새 기능
- fix: 버그 수정
- refactor: 리팩토링
- docs: 문서 변경
- test: 테스트
- chore: 빌드/설정

## 규칙
- 커밋 메시지는 변경 내용을 정확히 반영
- 한 줄 요약 + 필요 시 상세 본문
- 자동 커밋하지 않고 제안만 (사용자 확인 후 커밋)
